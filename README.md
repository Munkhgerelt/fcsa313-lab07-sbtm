## Ажиллуулах

Нэмэлт сан суулгах шаардлагагүй. Репозиторийг татаж аваад Node.js-ээр ажиллуулна.

```powershell
git clone https://github.com/Munkhgerelt/fcsa313-lab07-sbtm.git
cd fcsa313-lab07-sbtm
node app.js
```

Браузераар [http://localhost:3000](http://localhost:3000) хуудсыг нээнэ. Өөр сервер 3000 порт ашиглаж байвал эхлээд түүнийг зогсооно. Номын өгөгдөл зөвхөн санах ойд байдаг тул тайлан бүрийг дагахын өмнө серверийг `Ctrl+C`-ээр зогсоож, `node app.js` гэж дахин асаана; хуудсыг Reload хийх нь хангалтгүй.

## Дүгнэлт (debrief)

Олдсон зөрүүний тоогоор Supermodel аялал хамгийн үр дүнтэй байж, тоолуур, оны бичиглэл, товчны өнгө, хуучин холбоос, урт мөрийн харагдац, товчны үсгийн алдааг илрүүлсэн (BUG-01, 02, 03, 09, 11, 14). Fed-Ex аяллаар өгөгдлийг нэмэхээс хайх, устгах хүртэл дагаж үзэхэд буруу он, давхардал, үсэг ялгасан хайлт, буруу мессеж, өөрчлөгдсөн тусгай тэмдэгтүүд ажиглагдсан (BUG-05, 06, 07, 08, 12). Couch Potato аяллын хоосон оролт шаардлагатай талбарууд шалгагдахгүй байгааг хамгийн цөөн үйлдлээр харуулсан (BUG-04). Saboteur аяллаар эвдэрсэн JSON-д амжилт гэж хариулах болон `null` утгаар сервер зогсох хоёр өөр үр дагавар олдсон (BUG-10, 13). Синтаксийн хувьд зөв `null` бүх серверийг зогсоохыг анх тусад нь төлөвлөөгүй байсан бол нэг удаагийн холболтын тасалдлыг давтаж баталж чадаагүй тул шинэ согог гэж тооцоогүй. Дараагийн charter-т энэ тасалдлыг тусдаа процессын логтой судалж, одоогоор бүрэн шалгаагүй Firefox, гар утасны дэлгэц, зэрэгцээ хүсэлт, сүлжээ тасрах үеийн үйлдлийг хамруулах нь зүйтэй. Лаб 1-ийн Playwright тестийн файлууд энэ ажилд өгөөгүй учраас яг тэр багц аль согогийг барих байсныг батлах боломжгүй. Харин тохирох шалгалттай бол хоосон талбар, он, давхардал, хайлт, мессеж, тоолуур, өгөгдлийн текст, холбоос болон API-ийн хариуг Playwright ба HTTP түвшний тестээр барьж болно. Товчны өнгө болон урт мөрийн харагдац энгийн үйлдлийн тестэд анзаарагдахгүй өнгөрч болох тул энэ session-д дэлгэцийг харж үнэлэх нь хэрэгтэй байсан. Эдгээр харагдацын зөрүүг ч CSS-ийн утга, хэмжээ, зургийн харьцуулалтаар автоматжуулж болох учраас «зөвхөн хүний нүдээр л олдоно» гэж туйлшрахгүй, харин зөв хүлээлт сонгоход хүний үнэлгээ хэрэгтэй гэж үзэв.
