# BUG-10: Эвдэрсэн JSON хүсэлтэд HTTP 400-ийн оронд 200 OK буцаадаг

Орчин: Уншлагын жагсаалт v2.0; Codex in-app browser, Chromium 155 (хүсэлтийн User-Agent: Chrome/155.0.0.0); Windows 11 Pro 10.0.26300; Node.js v24.19.0; 2026-10-19.

Урьдчилсан нөхцөл: өмнөх серверийг `Ctrl+C`-ээр зогсоож, `node app.js` гэж шинээр асаасан; анхны **3 номтой**. Зөвхөн хуудсаа Reload хийх нь өгөгдлийг анхны төлөвт оруулахгүй.

## Дахин гаргах алхам

1. Репозиторийн үндсэн хавтсанд terminal нээнэ.
2. Доорх командыг ажиллуулна; `evidence/request-10.json` файлд `{broken` гэсэн эвдэрсэн JSON бий.
3. HTTP статусын мөр болон хариуны биеийг шалгана.

**Хүлээгдэж байсан:** Спецификацийн «буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана» дүрмээр HTTP `400` болон алдааны тайлбар ирнэ.

**Бодит үр дүн:** HTTP `200 OK`, `{"result":"OK"}` ирнэ. Дараах GET-д анхны гурван ном хэвээр байсан тул хүсэлтийг ном болгон хадгалаагүй атлаа амжилт гэж мэдээлсэн.

**Ноцтой байдал:** Major — API хэрэглэгч буруу хүсэлтийг амжилттай гэж ойлгоно. Статус кодын гэрээ шууд зөрчигдөж байна.

**Олдсон аялал:** Saboteur — Seedy district.

## Нэмэлт баримт ба хяналт

```powershell
curl.exe -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" --data-binary "@evidence/request-10.json"
```

API-ийн үндсэн нотолгоо: [bug-10-curl.txt](../evidence/bug-10-curl.txt). Энэ нь HTTP статусын мөр, бүх толгой, хариуны биетэй `curl -i`-ийн бүрэн гаралт. Дараах төлөв: [bug-10-after-curl.txt](../evidence/bug-10-after-curl.txt).
