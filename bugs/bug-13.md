# BUG-13: JSON null илгээхэд сервер бүрэн зогсдог

Орчин: Уншлагын жагсаалт v2.0; Codex in-app browser, Chromium 155 (хүсэлтийн User-Agent: Chrome/155.0.0.0); Windows 11 Pro 10.0.26300; Node.js v24.19.0; 2026-10-19.

Урьдчилсан нөхцөл: өмнөх серверийг `Ctrl+C`-ээр зогсоож, `node app.js` гэж шинээр асаасан; анхны **3 номтой**. Зөвхөн хуудсаа Reload хийх нь өгөгдлийг анхны төлөвт оруулахгүй.

## Дахин гаргах алхам

1. Репозиторийн үндсэн хавтсанд terminal нээнэ.
2. Доорх эхний командаар `evidence/request-13.json` доторх `null` утгыг POST илгээнэ.
3. Дараагийн GET командыг ажиллуулаад үндсэн хуудсыг дахин ачаална.

**Хүлээгдэж байсан:** Номын талбаруудтай объектын оронд `null` ирвэл сервер хүсэлтийг 4xx алдаагаар татгалзаж, дараах GET болон үндсэн хуудас ажилласаар байна. Спецификацийн буруу оролтын алдааны хариу болон нэг буруу хүсэлтээр бүх сервер зогсох ёсгүй гэсэн ердийн хүлээлтэд тулгуурласан; `null` нь синтаксийн хувьд зөв JSON.

**Бодит үр дүн:** POST HTTP хариу өгөлгүй холболтыг тасалсан: анхны гаралт `curl: (56) Recv failure: Connection was reset`. Дараах GET `curl: (7) Failed to connect ...` болсон. Node процесс зогсож, дахин асаах хүртэл апп ашиглах боломжгүй болсон.

**Ноцтой байдал:** Critical — Ганц хүсэлтээр бүх UI/API үйлчилгээг зогсоож, гараар сервер дахин асаах шаардлагатай болгодог.

**Олдсон аялал:** Saboteur — Seedy district.

## Нэмэлт баримт ба хяналт

```powershell
curl.exe -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" --data-binary "@evidence/request-13.json"
curl.exe -i http://localhost:3000/api/books
```

Бүрэн гаралтууд: [POST](../evidence/bug-13-curl.txt), [дараах GET](../evidence/bug-13-after-curl.txt). Сервер HTTP хариу өгөхөөс өмнө зогссон тул эхний файлд HTTP статусын мөр байхгүй. Холболт тасарсны `curl` код орчноос шалтгаалан өөр байж болох ч дараах GET ажиллахгүй болж, процесс зогсох үр дагавар нь гол шалгалт. Энэ нь `{broken` хүсэлтэд `200 OK` буцаасан BUG-10-аас өөр зан төлөв.

Oracle: багшийн Lab07 PDF-ийн 2-р хуудасны спецификаци; тусгайлан заасан хэсэгт ердийн хэрэглээний хүлээлт ашигласан.
