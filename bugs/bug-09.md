# BUG-09: Хуучин хувилбар холбоос HTTP 500 хуудас нээдэг

Орчин: Уншлагын жагсаалт v2.0; Codex in-app browser, Chromium 155 (хүсэлтийн User-Agent: Chrome/155.0.0.0); Windows 11 Pro 10.0.26300; Node.js v24.19.0; 2026-10-19.

Урьдчилсан нөхцөл: өмнөх серверийг `Ctrl+C`-ээр зогсоож, `node app.js` гэж шинээр асаасан; анхны **3 номтой**. Зөвхөн хуудсаа Reload хийх нь өгөгдлийг анхны төлөвт оруулахгүй.

## Дахин гаргах алхам

1. Браузераар `http://localhost:3000/` хуудсыг нээнэ.
2. Хуудасны доорх «Хуучин хувилбар» холбоосыг дарна.

**Хүлээгдэж байсан:** Бүх хуудас, холбоос ажиллах дүрмээр хуучин хувилбарын хуудас нээгдэнэ, серверийн дотоод алдаа харагдахгүй.

**Бодит үр дүн:** `http://localhost:3000/old` хуудас `Internal Server Error` гэсэн дан текст харуулж, HTTP `500 Internal Server Error` буцаадаг.

**Ноцтой байдал:** Minor — Нэмэлт хуудас ашиглах боломжгүй. Үндсэн жагсаалт болон API ажиллаж байгаа тул бүх апп зогссон тохиолдолтой адил үнэлээгүй.

**Олдсон аялал:** Supermodel — Tourist district.

## Нэмэлт баримт ба хяналт

Бүрэн HTTP хариу: [bug-09-curl.txt](../evidence/bug-09-curl.txt). API-аар давтах бол `curl.exe -i http://localhost:3000/old` гэж ажиллуулна. Үндсэн API амьд хэвээр байсны хяналт: [bug-09-main-still-available-curl.txt](../evidence/bug-09-main-still-available-curl.txt).
