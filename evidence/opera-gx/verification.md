# Opera GX дээрх нэмэлт давталт

2026-10-19-ний 16:01–16:05 (UTC+08:00) үед Opera GX **136.0.6008.111** дээр доорх UI шалгалтыг хийв. Хувилбарыг ажиллаж буй Opera GX-ийн executable файлын ProductVersion болон FileVersion утгаар шалгасан. Windows 11 Pro 10.0.26300, Node.js v24.19.0 ашигласан бөгөөд багшийн `app.js` өөрчлөгдөөгүй.

Энэ нь анхны 60 минутын session-ээс хойш хийсэн, автомат туслахтай нэмэлт давталт юм. Анхны session-ийн цаг, браузер, түүхий тэмдэглэлийг өөрчлөөгүй.

BUG-01–03-ыг нэг анхны төлөвөөс, BUG-04, 05, 06 бүрийг серверийг дахин асаасны дараа шалгасан. Хуудсыг Reload хийхэд серверийн санах ой дахь номын жагсаалт анхны төлөвт ордоггүй. Зургуудыг Opera GX цонхноос шууд хадгалсан; тайрч эсвэл агуулгыг нь засварлаагүй. Бодит цагтай ажиглалтууд [retest.jsonl](retest.jsonl)-д бий.

BUG-07-ын `Clean` хяналтын хайлт нэг мөр буцаасныг [зурагт](../../screenshots/opera-gx/bug-07-control.jpg) хадгалсан. Opera дахь `clean` харьцуулалтыг дуусгаагүй тул энэ зургийг BUG-07 бүрэн давтагдсан гэсэн нотолгоо болгоогүй. Хэрэглэгчийн ажилд саад болохгүй байх хүсэлтийн дагуу цонхны фокус авдаг үйлдлүүдийг энд зогсоосон. BUG-08, 09, 11, 12, 14-ийн Opera UI давталт хийгдээгүй; тэдгээрийн анхны Chromium нотолгоо хэвээр бий.
